## Design Constraints (From Skills — Do Not Violate)

From design-basics guardrails:
- Max 3 primary colors per palette (60-30-10 rule)
- Body text 16px minimum
- 8px grid spacing system
- Touch targets 44px minimum
- WCAG AA contrast (4.5:1 body, 3:1 large text)
- Never use color as the sole differentiator
- All interactive elements: hover, focus-visible, active, disabled states

From premium-design (Mode: Modern Minimalist for dashboards):
- Single accent color for CTAs and active states
- Border-radius: 6-12px for cards, 9999px for pills
- Shadows: subtle only (no spread)
- No glassmorphism/backdrop-filter on scrolling content
- Animate only transform and opacity

From emil-design-eng:
- Button press: scale(0.97), 120-160ms ease-out
- Entry animations: start from scale(0.95), not scale(0)
- Always use custom easing curves, never built-in CSS easings
- stagger delays: 30-80ms between items
- Popovers/ tooltips: origin-aware transform-origin
- UI animations under 300ms

From high-end-visual-design:
- Double-bezel card architecture (outer shell + inner core)
- Macro-whitespace (py-24 to py-40 for sections)
- No Inter, Roboto, Lucide standard icons (use Geist, Phosphor Light)
- No generic 1px solid borders
- Custom cubic-bezier transitions (no linear or ease-in-out)
- GPU-safe animation (transform + opacity only)
